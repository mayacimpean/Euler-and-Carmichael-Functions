# Euler-and-Carmichael-Functions

The following code runs the Euler Totient and Carmichael Functions for a range of positive integer inputs n, and records their computational running times.
The code implements a prime factorisation algorithm using trial division, the Euler Totient algorithm using the Euler product formula, and the Carmichael function algorithm implementing a Euclidean algorithm within a lowest common multiple algorithm.
The outputted running times can be used to compute a graph of time against n for both functions, allowing for comparison between the speed at which each function is performed.

There is also a section of code computing RSA encryption and decryption of some message, which records the computational running times for each function, allowing for a comparison between the relative speeds of each function's implementation in RSA to be drawn.
