# Euler-and-Carmichael-Functions

The following code runs the Euler Totient and Carmichael Functions for a range of positive integer inputs n, and records their computational running times.
The code implements a prime factorisation algorithm using trial division, the Euler product formula and a Euclidean algorithm within a lowest common multiple algorithm.
The outputted running times can be used to compute a graph of time against n for both functions, allowing for comparison between the speed at which each function is performed.
